# Agent Evaluation Rubric

Use this rubric to review whether an agent is a professional system rather than a prompt-only assistant.

## Dimensions

| Dimension | Questions |
|---|---|
| Role clarity | Is the agent's domain and boundary clear? |
| Knowledge | Does it have an indexed knowledge base? |
| Memory | Does it preserve long-term decisions and preferences safely? |
| Workflows | Are repeatable tasks specified with steps and failure policy? |
| Tools | Are execution paths stable and structured? |
| Evidence | Are conclusions tied to evidence levels? |
| Risk | Are high-risk actions gated by review or approval? |
| Feedback | Can humans rate, correct, and improve the agent? |
| Delivery | Can it produce useful reports and next steps? |
| Ops | Can tasks/runs be monitored and reviewed? |

## Output

A review should include:

- maturity level L0-L6;
- strengths;
- gaps;
- P0/P1/P2 next steps;
- risk boundary;
- evidence limitations.
