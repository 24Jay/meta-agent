# Example Research Summary

## Topic

Professional agent design for teams that need reviewable and improvable AI agents.

## Evidence

- Professional agents need explicit capability boundaries so users know what the agent can and cannot do.
- Workflows make repeated procedures easier to review than ad-hoc prompts.
- Evidence levels help separate observed facts, cited claims, and inferred recommendations.
- Risk levels define when a human must review or approve an action.
- Feedback should become a candidate for memory or knowledge only after review.

## Recommendations

- Start with read-only workflows before adding write actions or external side effects.
- Keep capability matrices close to agent definitions.
- Record run outcomes so reviewers can trace what happened.
- Convert positive or corrective feedback into proposed memory candidates, not automatic memory writes.
